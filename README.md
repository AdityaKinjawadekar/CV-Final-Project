# CV-Final-Project
Final project for the computer vision class.

Contains two codes,
1. To generate hadamard masks that are needed to display on the Digital micromirror device.
2. Generate datacube from the spectral data. This is done by doing inverse hadamard masks and reconstructing data cube. 
  This code also has an unsupervised Kmeans clustering algorithm that classifies the pixles into stars and galaxies based on the spectral features.
